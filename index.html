Forward-Pass Adaptation: Reproducing ntkmirror and Probing How It Scales with Gate Budget

Independent reproduction and two scaling experiments on Qwen2.5-0.5B-Instruct · single free-tier T4 GPU

reproductionscaling studyNTK duality

This note reproduces the core composition result of ntkmirror (Hassana Labs) and then runs two experiments the repository does not cover: how the method behaves as the number of forward-pass gates is varied across nearly two orders of magnitude. The reproduction matches the published figures. The novel finding is a clean dissociation: task accuracy and NTK-duality do not scale together. Adding gates keeps improving task accuracy well past the point where the controller stops becoming a better dual of a fine-tuning step. Past roughly 1,024 gates the two come apart.

Method in brief

ntkmirror adapts a frozen language model without modifying its weights. In place of fine-tuning, it learns a sparse set of per-channel multipliers applied during the forward pass: each selected residual-stream channel is scaled by exp(s), where s is a bounded log-gate (here |s| ≤ 0.05). A controller is a few thousand such gates, fit by a short optimisation while the base weights stay frozen. Two properties make it notable: it adapts a model at zero inference cost and without touching weights, and independently-fit controllers can be summed and still retain both behaviours, because the gate vectors for different tasks are close to orthogonal.

1 · Reproducing the composition result

Using the repository's disjoint-composition configuration at full settings (5,000 gates, 240 steps), a maths controller was fit on GSM8K and a code controller on MBPP, then composed by gate addition.

The composed controller improves on both tasks simultaneously, staying close to each specialist. Measured gate cosine between the two controllers was 0.025, consistent with the published value of approximately 0.017 for this GSM8K + MBPP pairing.

One detail is worth stating directly: the code controller applied alone slightly degraded maths (0.738 versus the 0.719 baseline), yet in the composed controller the maths contribution dominated and maths recovered to 0.616. Composition does not merely avoid interference; where the two controllers competed, the beneficial direction prevailed. The reproduction is successful.

2 · Does composition survive across gate budgets?

The clean-composition result is demonstrated at a single gate count. The practical question: if gate budget is scaled up to chase accuracy, does composability degrade? Six gate counts (256 to 5,000) were swept at a reduced configuration for T4 feasibility, measuring single-task accuracy, composed accuracy on both tasks, and gate cosine at each point.

Accuracy improves monotonically with gate count and has not plateaued at 5,000 (maths 0.593 → 0.540; code 0.895 → 0.780). The composition gap stays small and flat across the whole range, about 0.004 on maths at both the smallest and largest budgets, so scaling capacity does not cost composability. Gate cosine stays near zero across all six budgets (within roughly ±0.018), with no systematic trend.

A prior expectation that cosine might rise with gate count was not supported once the full sweep was run; the variation is noise around zero rather than a trend. It is reported here as a corrected expectation rather than quietly dropped.

3 · Does reachability scale with gate budget?

Accuracy is not the quantity the NTK-mirror theorem concerns. The theorem is about whether a controller is a genuine dual of a fine-tuning step: whether the gate tangent can reproduce the output displacement a weight update would induce. The repository's dual-diagnose tool measures this directly by taking a small reversible weight step, measuring its projected-logit displacement, and testing whether the gate basis can realise that field. The reported residual is lower when the field is more reachable.

The same six gate counts were swept, running dual-diagnose on each trained controller with the full-weight target scoped to the attention projections (q_proj, k_proj, v_proj, o_proj) for feasibility.

Reachability improves steeply, then saturates. The residual falls from 10.17 at 256 gates to 4.24 at 1,024 (a >2.4× improvement), then bounces in a 3.5–4.9 band for all larger budgets with no further systematic gain. This matches a prediction made in advance: reachability would improve with capacity but likely saturate, because beyond a point reachability is governed by which channels are gated rather than how many.

The key observation is the dissociation. Accuracy improves monotonically across the entire range, while reachability stops improving after roughly 1,024 gates. The gates added beyond saturation therefore improve task performance through a mechanism other than better approximating the full-weight SGD field; the controller finds task-helpful adjustments that are not what fine-tuning would have done. As a consequence, task performance is not a reliable proxy for NTK-duality in this regime, and accuracy gains alone should not be read as evidence that the duality is tightening.

Caveats

The sweeps used small evaluation sets and reduced step counts to remain feasible on a single T4, so absolute values would shift at full scale; the trends, not the exact figures, are the result. Each point is a single run without error bars. The code task was consistently noisier than maths. The reachability residuals are large in absolute terms everywhere, scoped to attention weights at a small step size, so the result concerns the trend rather than the controller being a close dual in absolute terms. The plateau is not perfectly smooth (the 2,000-gate point sits slightly above 1,024), so the precise location of the knee should not be over-interpreted.

An open question

The information-geometry framing of learning as compression appears to align naturally with what a controller is: a compact (~200 KB) encoding of a task adaptation rather than that adaptation distributed across billions of weights. If that reading holds, the flat composition gap might indicate that the compressed encodings of different tasks occupy nearly independent subspaces and therefore superpose without interference. This is offered as a question rather than a claim.

All experiments used the public ntkmirror repository cloned fresh on a free Colab T4, on Qwen2.5-0.5B-Instruct. Sweep harnesses drive the existing CLI over gate counts; raw results and figures saved per run.
